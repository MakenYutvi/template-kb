# Workflow бюджета контекста

Используй этот workflow, чтобы не загружать лишний контекст и не превращать каждый запрос в полный обход репозитория.

## Принцип

Читать нужно минимальный набор файлов, достаточный для надежного ответа.

Применимые инструкции обязательны. Уже прочитанные неизменённые входы повторно не загружай. README/SETUP нужны для настройки и структуры, schema — при изменении wiki. Краткий старт для общего контекста: инструкции → этот маршрут → wiki/index и нужная область current-status. Архивы статуса/журнала не входят в обязательный старт.

## Маршруты задач

| Задача | Первый вход | Когда расширять чтение |
|---|---|---|
| Ответить из KB | [query](query.md), тематическая wiki/index | Точные числа, статусы, решения — первичный source |
| Восстановить работу | [current-status](../current-status.md), нужная область | Исторический вопрос — поиск по истории, затем найденный фрагмент |
| Добавить источник | [ingest](ingest.md) или [meeting-ingest](meeting-ingest.md) | Несколько тем, чувствительные данные — [triage](triage.md) |
| Уточнить память | [writeback](writeback.md) и источник | Противоречие, новый процесс или неясная приватность — соответствующая ветка |
| Сократить страницу | [compact-document](../../prompts/compact-document.md) | Must Preserve, история, входящие ссылки; массовая миграция требует расширения |
| Проверить состояние KB | [weekly-review](../../prompts/weekly-review.md) | Выбранные вопросы → адресные первичные источники → один итог |

Для обзора сначала определи область и проверяемые утверждения. Не заменяй недоступный источник догадкой и не расширяй обзор до всех outputs. Этот маршрут не вводит расписание, отдельный runner или обязательный учёт стоимости.

## Уровни чтения

### Уровень 0: конкретный файл

Используй, если пользователь указывает конкретный файл или маленькую папку.

Читать:

- указанный файл;
- ближайшие локальные инструкции, если они есть;
- source-файлы только при необходимости.

### Уровень 1: wiki entry

Используй для восстановления общего контекста.

Читать:

- `AGENTS.md`;
- `wiki/index.md`;
- `wiki/current-status.md`;
- релевантную wiki-страницу.

### Уровень 2: проверка source

Используй для точных ответов, решений и правок.

Читать:

- relevant wiki;
- source-файлы из `raw/`;
- decision log, если решение уже принималось.

### Уровень 3: lint или migration

Используй для структурных изменений, lint и крупных миграций.

Читать:

- `AGENTS.md`;
- `.ai/contract.md`;
- `wiki/index.md`;
- `wiki/schema.md`;
- только применимые к изменению процедуры из `wiki/workflows/`;
- `manifests/sources.md`;
- релевантные source-области.

## Правила

- Не читать весь `raw/` без причины.
- Не доверять `wiki/` для точных чисел, дат и юридических формулировок без source verification.
- Если ответ стал полезным устойчивым артефактом, применить `writeback.md`.
- Если найдено противоречие, применить `source-provenance.md`.
- Current-status обновлять по областям; значимую историю сохранять отдельно с указателем. При сокращении не удалять факты ради размера. Байты и строки можно сравнивать, но нельзя называть измеренными токенами или экономией.
